# 元ZIPのスクリプトテンプレート

「パーティクル(R) ver3.54B」の配布ZIPから、次のファイルを内容を変更せず収録しています。

- `@particle_ri_ver3.anm`
- `@標準_particle_anime.anm`
- `格子マスク_particle_anime.anm`
- `自作関数サンプル/*.txt`（11件）

`.anm` は AviUtl 1.x 用の元スクリプトであり、AviUtl2 のプラグインとして自動読込するファイルではありません。旧版の設定名、既定値、スクリプト記述を確認するための原本テンプレートです。このため、配布パッケージでは `Plugin` や `Script` ではなく `templates/original` に格納しています。

`自作関数サンプル` のコードは、AviUtl2 で同じオブジェクトへ「スクリプト制御」を追加して貼り付けるか、「パス」でファイルを指定して使用します。標準「スクリプト制御」は本体の上下どちらに置いても読み取られます。11件すべてを原本ファイルから読み、終点まで数値評価する回帰テストを行っています。「擬似オブジェクト追跡」2件の `obj.getvalue` は直前レイヤーのXYZ座標を参照します。現在の対応範囲と設定手順は、配布パッケージの `docs/original-article-guide.md` と `docs/compatibility.md` を参照してください。

原本の文字コードを含むバイト列を維持しているため、文字化けして見える場合は Shift_JIS（CP932）として開いてください。
