# P3 の演算仕様と未確定事項

この文書は 0.4.0 の独立した拡張効果でも使用する P3 の **実装仕様** です。旧 DLL の挙動を実機で照合した結果ではありません。既定値をゼロ／無効にすると P2 の基本挙動を保ちます。

## 時刻と乱数

- AviUtl2 から受け取るオブジェクト内時刻（秒）を使い、各フレームで出生時刻から再計算します。前フレームの状態は使いません。
- 個別ばらつきは各粒子の MT19937 から対称一様乱数を得て、対象値に `1±設定値%` を掛けます。旧 DLL の乱数消費順とは未照合です。
- 頻度変調は `rate(t)=基本頻度/10×(1+A sin(2πt/周期))` とし、累積発生数から出生時刻を逆算します。これによりシーク順に関係なく同じ発生時刻になります。
- 運動時間は `max(0,(実年齢+時間ずれ)×進行速度)` です。寿命判定は実年齢で行います。時間ずれが正なら出生直後から進んだ運動状態が表示されます。
- 速度・透過率・拡大率の周期変調は運動時間で評価します。旧「時間」の13系列・タイプ指定とは別の暫定仕様です。

## 1粒子の運動順

1. 発生形状、方向、個別ばらつきを粒子のシードから決めます。
2. 出生位置・初速度へ重力、風の線形カーブ、空気抵抗、速度変調、集結力を加えます。
3. 時間指定の分散インパルスを適用します。反射時分散が有効なら最初の反射直後に1回適用します。
4. 各軸の境界反射を処理し、反発係数を速度へ掛けます。
5. 集結点の到着半径に入った場合の停止／消失と、急停止を処理します。
6. 最後に円／球面運動で位置を変換し、回転・透過率・拡大率を評価します。軌跡は過去時刻を同じ手順で再計算します。

運動は基本 1/120 秒刻みで積分し、イベント時刻ではステップを分割します。長い運動時間の計算量を抑えるため粒子あたりの積分回数に上限を設けています。軌跡は粒子最大10,000個、追加描画最大10,000個、粒子あたり最大16点です。上限を超える設定では古い発生イベントと軌跡点が省略されます。

## 旧版との未照合点

- 風と時間2の別オブジェクトからの伝播、`throughf` の消費順。
- 旧回転の揺れ、反射のタイプ分岐と球、分散の同期、円運動の中心タイプ。
- 空間場のノイズ関数と、挙動パターン 0〜101。
- 旧「軌跡」の図形・色・重力・消失時刻と描画順。
- 旧 DLL の数値基準がないため、正確なイベント順、角度、座標、画像差分。
