# P4 計算コアの実装状況（0.5.1）

P4 の11項目に追加した計算・描画コアを記録する。0.5.1 では旧版の UI と設定キーを優先して組み直したため、下表にある0.4.1用設定の一部は旧 UI からまだ接続できない。利用可能範囲は [互換性一覧](compatibility.md) を優先する。

本体と拡張効果の配置順は [本体と拡張効果](stacked-effects.md) を参照する。旧統合型「パーティクル(R) 基本版」は0.5.0以降の配布対象から外した。

| P4 項目 | 実装と設定 | 旧版との差・制限 |
|---|---|---|
| 他レイヤー追跡 | `追跡レイヤー` の位置差を粒子と軌跡へ加算。`追跡時刻` で現在または各粒子の出生時刻を選択 | 姿勢や拡大率は追跡しない。削除済み参照は無効にしてログへ警告 |
| 画像マスク衝突 | `マスクレイヤー` の現在画像のアルファを読み、内側／外側クリップ、反射、停止、消失を選択。反発係数を指定可能 | マスクはシーン中央基準の静止画像。1フレーム中の全粒子経路へ同じ現在時刻の画像を適用。細い境界は最大128分割で交差検出 |
| 共有風・時間2 | 共有先レイヤーにある有効な同名フィルタのトラックを現在時刻で読み、風と時間変調へ反映 | 値の読み込みのみで再帰評価しない。効果名や対象が違う場合はローカル値を使い警告 |
| テキスト | 「テキスト」拡張の `出力単位=2` で文字、`3` で行ごとに元画像を分割。Unicode の文字数を使用 | 元画像は同じ文字列を表示した AviUtl2 テキストオブジェクトを想定。フォントはそのオブジェクトの設定を使用。等幅セルによる近似分割 |
| 動画・連番 | 「動画」拡張で現在フレームの動画オブジェクトを素材化。「パス」拡張の `####` をフレーム番号に置換した画像連番を読み、現在／出生／粒子年齢の時刻から番号を選択 | 動画ファイルそのものを各粒子の出生時刻へシークする機能はない。欠損フレームは現在素材へ戻す。1フレーム中の連番参照は最大4096種類 |
| 粒子別フィルタ | 効果名と `key=value;...` を指定し、粒子ごとの複製画像へ AviUtl2 の `exec_effect` を適用。値に `{id}`、`{age_ms}`、`{birth_ms}` を使用可能 | 画像・連番素材に適用。効果名・設定が無効なら元画像を描きログへ警告。効果の対応状況は AviUtl2 側に依存 |
| ファンネル | 親粒子から最大8円環の子粒子を生成。数、半径、縮尺、公転、自転を設定 | 総子粒子は1万個まで。旧版の複雑な同期・個別変形は未照合 |
| メッシュ | 距離内の後続粒子を発生順で結ぶ線と、近接する2粒子を使う三角面。幅、色、透明度を設定 | 先頭512粒子まで。旧版の接続順や面材質は未照合 |
| 基本立体 | P5でタイプ0～5を正六面体、球、錐体、双錐体、曲面、奥行き形状へ拡張。XYZ回転、分割数、曲率、奥行き、サイズ、RGBと透過率を反映 | 現在は単色材質。タイプ6のPMD由来 `.dat` は未対応 |
| ガラス化 | 描画前の `Framebuffer` を複製し、粒子位置の矩形へずらした背景 UV を描く | 二次元の単一オフセット屈折。背景を取得できない場合は通常素材へ戻す |
| 10帯域音 | PCM16 WAV を最大128 MiBまで読み、10中心周波数から選んだ帯域を任意時刻で解析して速度・頻度・透過率・拡大率へ反映 | 帯域1～10を選択。各変調は現在時刻の同じ値を粒子群全体へ適用。非対応形式・欠損ファイルは無音扱いでログへ警告。先頭再生や事前解析を要求しない |

## 時刻、参照と負荷の規則

- 共有風・時間、マスク、通常画像、動画オブジェクト、ガラス背景は現在時刻のスナップショットを使用する。追跡位置は現在／出生を選択する。連番は現在／出生／粒子年齢を選択する。
- レイヤーの自己参照と欠損参照は無効。画像取得時は追加効果を評価しないため、参照先の効果が互いを指しても再帰描画しない。共有値はトラックだけを読み、リンク先を再評価しない。
- マスクは最大16,777,216画素。メッシュは先頭512粒子、ファンネルは子粒子1万個。音声ファイルは128 MiB以下。制限を超えた場合は該当機能を無効にするか上限で打ち切る。
- この版では欠損素材・参照・無効効果をログで通知し、描画可能な素材へ戻す。UI上のリンク番号そのものには状態マークを表示しない。

## 検証済み

- `cargo test --workspace --offline`：コア・ホスト補助の単体テスト。マスク交差、シーク再現、WAV帯域、連番パスを含む。
- `au2 develop --skip-start`：開発版へビルド・配置。
- AviUtl2 2.1.9 を非表示起動し、ログで本体と31拡張の計32効果を登録エラーなしで確認。`initializeProc()` のスタックオーバーフローは再発していない。

積層効果を適用した画面比較、旧 DLL との定量比較、連番・ガラス・立体を含む実プロジェクトの書き出し比較は未実施。旧版32項目の対応度は [互換性一覧](compatibility.md) を参照。
