# 旧版との対応状況（0.8.0-beta.2）

0.8.0-beta.2 は本体と31拡張を効果追加メニューの「パーティクル(R)」ラベルへまとめ、旧版のトラックと `--dialog` の項目を元の範囲・初期値で生成する。範囲が0..1だけの旧トラック、および `/chk` の設定はチェックボックス、それ以外の単一数値120項目はスライダーとして表示する。配列・`nil`・文字列・色など構造化値147項目は旧記法の入力欄を維持する。チェック、詳細設定のラベルと既定値も旧スクリプトから生成する。表示名にはスクリプトの命名慣習に合わせて `@particle2r` を付け、下表では比較しやすいよう旧版の名前を記載する。下表は UI の有無ではなく、旧設定が現在の描画処理へ接続されている範囲を示す。元と同じく拡張効果を本体より上に積む。旧 DLL との視覚的一致は保証しない。

| 旧項目 | この版での状態 |
|---|---|
| 1 パーティクル本体 | 点発生、頻度、方向・拡散、寿命、XYZ 重力、透過率・拡大率の線形変化、シードを実装。「終了時に消える」で各粒子の寿命をオブジェクト終端までに切り詰める。旧 DLL の時系列・乱数消費順は未照合。 |
| 2 パス | 1～10番へ外部ファイルを登録し、「出力」「挙動」の数値Lua、「画像」の単体／フォルダ素材、「テキスト」の外部文章、「ファンネル」の `pathN` 画像、「立体物」タイプ6の参照確認へ接続。UTF-8、UTF-8 BOM、Shift_JISに対応。ファンネルのパステキストとPMD由来 `.dat` の読込は未対応。 |
| 3 前後表裏その他切替 | 描画順、表／裏選別、裏1の正面化、回転表現1～6、頻度逆転、逆再生、進行方向を接続。表裏合成は未照合。ゲームと未使用の時間短縮は対象外。 |
| 4 方向と格子 | Z 方向・拡散・重力を実装。旧角度変換との照合および格子は未対応。 |
| 5 出力 | 点・水平線・箱内・球面からの発生を実装。タイプ8は、オプション0で「数」と同じパス番号の外部ファイル、オプション1で同じオブジェクトの標準「スクリプト制御」にある `xyz(t)` / `xyzd(t)` を発生位置・方向へ適用する（標準効果の上下位置は問わない）。`xyzd` のXY角度は旧版と同じく `(sin(角度), cos(角度))` で速度へ変換する。タイプ1〜7の旧分岐は未照合。 |
| 6 回転 | Z 軸の初期角度、一定回転速度、XYZ 回転加速度を実装。初期角度は0、基本の回転速度は旧版どおり60度/秒。`rotxyz` / `degvxyz` は `{x,y,z}` と単独数値を解釈する。揺れ・反転・上限は未対応。 |
| 7 集結点 | 単一アンカーへの一定加速度、到着後の停止・消失を実装。最大5アンカー、連結、角度指定は未対応。 |
| 8 拡大率と透過率 | 基本の始点・終点の線形補間を実装。中点・個別変化は未対応。 |
| 9 フィルター | `ﾌｨﾙﾀｰ名 (nae)` を AviUtl2 の粒子別効果名へ接続。変化値、固定値、効果順は未接続。 |
| 10 フィルター(単色化専用) | 粒子別効果で同名の AviUtl2 効果が使える場合のみ適用可能。旧版の専用パラメータは未対応。 |
| 11 個別微調整 | 旧 UI を表示し、速度値の一部をばらつきへ近似接続。寿命・回転・重力・透過率・拡大率などは旧 UI から未接続。 |
| 12 時間 | `1速度` と先頭の `周期ms` を正弦速度変調へ近似接続。旧13系列、タイプ0〜5、任意グラフは未対応。 |
| 13 時間2 | 旧 UI を表示。グラフ選択と旧版の暗黙伝播は未接続。 |
| 14 跳ね返り | XYZ 軸の境界反射と共通反発係数を実装。旧タイプ1〜4、球、確率分岐等は未対応。 |
| 15 跳ね返り2 | `ﾚｲﾔｰ (relayer)` の先頭値をマスク参照へ接続し、反射として処理。複数レイヤー、各タイプ、時間変化は未接続。 |
| 16 テキスト | `テキスト (pstr)` と `ﾊﾟｽ取得0~10` を文字／行分割へ接続。「出力を一文字から行に」を反映。フォント、装飾、色、切替規則は未接続。 |
| 17 画像 | パス番号0では現在画像、1～10では「パス」の単体PNG/JPEG/BMPまたは同じフォルダの画像を使用。「ぱらばら」は粒子IDから決定的に選択。動画ファイル、形クリッピング、背景色は未接続。 |
| 18 動画 | 現在画像を動画素材として扱う。再生位置、速度、ランダム、同期、粒子別シークは未接続。 |
| 19 風 | 旧 UI を表示。旧グラフデータを現在の風計算へ変換する処理は未接続。 |
| 20 挙動 | `自作関数=1` で `vector(t)` を評価し、返されたXYZ速度を粒子年齢で数値積分して移動へ加算。`スクリプト制御記述=1` は標準「スクリプト制御」、0は「取得パス番号」の外部ファイルを使用。ゆらぎ、パターン、不審動作は未対応。 |
| 21 挙動2 | 指定時刻または反射時の1回の分散インパルスと指定時刻の急停止を実装。旧同期・イベント順・個別時刻は未照合。 |
| 22 挙動3 | XY/XZ/YZ 円運動と球面回転、半径速度を実装。旧中心タイプやランダム角速度は未対応。 |
| 23 挙動4 | 旧 UI を表示。旧放射時間・活動時間テーブルと現在の時間変換は未接続。 |
| 24 空間場 | **未対応**。旧 DLL の場の式が未復元のため、近似ノイズは導入していない。 |
| 25 軌跡 | 残像・白色帯・点の3種と寿命後の短い残存を実装。旧図形・色・重力・描画順との一致は未確認。 |
| 26 ファンネル | 最大8円環の子粒子を生成。数・半径・縮尺・公転・自転と `図形=path1`～`path10` の画像素材を接続し、総数は10,000個。パステキスト、標準図形指定、同期・個別変形は未照合。 |
| 27 メッシュ | `透過率`を接続。距離・幅・色は現在の既定値を使用し、旧版の接続順・材質は未照合。 |
| 28 立体物 | タイプ0～5を正六面体、球、錐体、双錐体、曲面、奥行き形状として三角面描画し、大きさ、分割数、曲率、奥行きを接続。現在は単色材質。タイプ6のパスは認識するがPMD由来 `.dat` は未対応。 |
| 29 ガラス化(二次元) | `倍率`を描画サイズへ接続。水平・垂直位置、エッジ、反転と旧屈折式は未接続。 |
| 30 ユーザーカスタムオブジェクト | beta対象外。同梱定義はすべて `obj.load` / `obj.draw` / `obj.drawpoly` 等の旧描画APIに依存し、純粋な数値・頂点戻り値ではない。 |
| 31 他作アニメーション効果オプション | beta対象外。変換後効果の並び順と任意Lua環境に依存するため、対象名を特定できないまま実行しない。 |
| 32 音 | `取得位置`を帯域番号へ接続。旧版の現在音取得・録音と、移植コアの WAV ファイル指定を結ぶ UI は未接続のため、現状は実質無音。 |

スクリプト制御は `math`、`string`、`table` と `obj.layer/time/totaltime/frame/totalframe/framerate` を提供する専用 Lua 状態で実行する。`framerate` はプロジェクト値を使用する。同梱の「擬似オブジェクト追跡」2例で使う `obj.getvalue(layer..".x/y/z", t)` は、直前レイヤーの出力座標を補間して返す。参照不能な値は0を返して処理を継続する。任意レイヤー・任意プロパティの取得、`obj.rand`、描画関数は未対応。曲線は最大8192点、毎秒240点を上限に事前評価する。

P3 の演算順は [P3 仕様メモ](p3-design.md) に記録しています。旧版の `.anm`、`.exa`、`.exo`、`.aup` は直接読み込めません。シーク再現性はコアのテストで確認しています。AviUtl2 実機での視覚比較と旧 DLL の基準データ比較はまだ行っていません。
