# 旧版との対応状況（0.2.1）

| 旧項目 | この版での状態 |
|---|---|
| 1 パーティクル本体 | 点発生、頻度、方向・拡散、寿命、XYZ 重力、透過率・拡大率の線形変化、シードを実装。旧 DLL の時系列・乱数消費順は未照合。 |
| 2 パス | 未対応。相対パスや連番の読み込みは未実装。 |
| 3 前後表裏その他切替 | 未対応。 |
| 4 方向と格子 | Z 方向・拡散・重力を実装。旧角度変換との照合および格子は未対応。 |
| 5 出力 | 点・水平線・箱内・球面からの発生を実装。旧 8 種の出力タイプとの対応は未照合。 |
| 6 回転 | Z 軸の初期ランダム角度、一定回転速度、XYZ 回転加速度を実装。揺れ・反転・上限は未対応。 |
| 7 集結点 | 単一アンカーへの一定加速度、到着後の停止・消失を実装。最大5アンカー、連結、角度指定は未対応。 |
| 8 拡大率と透過率 | 基本の始点・終点の線形補間を実装。中点・個別変化は未対応。 |
| 9 フィルター | 未対応。 |
| 10 フィルター(単色化専用) | 未対応。 |
| 11 個別微調整 | 速度・寿命・回転速度・重力・透過率・拡大率の粒子別ばらつきを実装。頻度・加速度・風力等は未対応。 |
| 12 時間 | 頻度・速度・透過率・拡大率の正弦周期変調を実装。旧13系列、タイプ0〜5、任意グラフとの一致は未確認。 |
| 13 時間2 | 未対応。 |
| 14 跳ね返り | XYZ 軸の境界反射と共通反発係数を実装。旧タイプ1〜4、球、確率分岐等は未対応。 |
| 15 跳ね返り2 | 未対応。 |
| 16 テキスト | 元のテキストオブジェクトを画像として粒子化可能。旧項目固有の文字・行別出力は未対応。 |
| 17 画像 | 元の画像オブジェクトを粒子化可能。旧項目固有の画像選択は未対応。 |
| 18 動画 | 元の動画オブジェクトの現在画像を粒子化可能。粒子ごとの時間ずれは未対応。 |
| 19 風 | 同一フィルタ内の開始・終了 2 点間の線形加速度カーブと空気抵抗を実装。別オブジェクト／上位レイヤーからの伝播は未対応。 |
| 20 挙動 | 未対応。 |
| 21 挙動2 | 指定時刻または反射時の1回の分散インパルスと指定時刻の急停止を実装。旧同期・イベント順・個別時刻は未照合。 |
| 22 挙動3 | XY/XZ/YZ 円運動と球面回転、半径速度を実装。旧中心タイプやランダム角速度は未対応。 |
| 23 挙動4 | 運動の時間倍率とオフセットを実装。旧放射時間・活動時間テーブルや微分表示は未対応。 |
| 24 空間場 | **未対応**。旧 DLL の場の式が未復元のため、近似ノイズは導入していない。 |
| 25 軌跡 | 残像・白色帯・点の3種と寿命後の短い残存を実装。旧図形・色・重力・描画順との一致は未確認。 |
| 26 ファンネル | 未対応。 |
| 27 メッシュ | 未対応。 |
| 28 立体物 | 未対応。 |
| 29 ガラス化(二次元) | 未対応。 |
| 30 ユーザーカスタムオブジェクト | 未対応。 |
| 31 他作アニメーション効果オプション | 未対応。 |
| 32 音 | 未対応。 |

P3 の演算順は [P3 仕様メモ](p3-design.md) に記録しています。旧版の `.anm`、`.exa`、`.exo`、`.aup` は直接読み込めません。シーク再現性はコアのテストで確認しています。AviUtl2 実機での視覚比較と旧 DLL の基準データ比較はまだ行っていません。
