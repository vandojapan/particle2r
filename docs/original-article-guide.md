# さつき氏の「拡張パーティクル(R)の使い方」と対照する

対象は[さつき氏の第1回まとめ](https://satsuki-ssd.blog.jp/archives/11460552.html)と、その目次にある第2～13回です。0.8.0-beta.2 は、記事で使われる ver3.5 系の効果名と、同梱 ver3.54B スクリプトの設定名を AviUtl2 の UI に表示します。効果名の末尾には `@particle2r` が付きます（例: `パーティクル本体@particle2r`）。

## 基本操作

記事と同じく、画像・図形・テキストなどへ「パーティクル本体@particle2r」を追加し、必要な拡張効果を本体より上へ追加します。拡張効果は複数併用できます。

```text
元画像オブジェクト
  出力                 ← 必要な拡張効果
  風                   ← 必要な拡張効果
  パーティクル本体     ← 最下段で描画
```

記事中の `@風` は AviUtl2 では「風@particle2r」を選びます。「回転@particle2r」と「テキスト@particle2r」も、末尾suffixによりAviUtl2標準効果と区別されます。それ以外もすべて末尾に `@particle2r` が付きます。

各効果の先頭に旧トラックとチェック項目があります。「詳細設定（旧版の『設定』）」を開くと、旧 `--dialog` の項目が並びます。たとえば本体の `同時発生数 (sync)` は、記事の「同時発生数」と元スクリプトの変数 `sync` の両方に対応します。

詳細設定の単一数値はスライダーで操作できます。配列、`nil`、文字列、色などの構造化値は旧スクリプト記法を維持しています。

| 値の種類 | 入力例 | 意味 |
|---|---|---|
| 数値 | `3` | 寿命、速度、時刻など |
| 配列 | `{100,50}` | 始点と終点など複数値 |
| 未指定 | `nil` | その補助機能を使わない |
| 文字列 | `"単色化"` | 効果名、図形名、式など |
| 色 | `0xff0000` | 16進RGB |

## 記事の目次との対応

UI は全32効果を登録しています。「接続済み」は主要項目が現在の Rust レンダラーへ渡ることを示します。旧版と同じ計算結果を保証する表示ではありません。

| 元記事 | AviUtl2 で選ぶ効果 | 現在の描画接続 |
|---|---|---|
| 第2回 本体 | パーティクル本体 | 速度、頻度、方向、拡散、重力、寿命、透過率、拡大率、シードを接続 |
| 第3回 | パス、前後表裏その他切替、方向と格子 | パス番号による外部Lua・素材参照、前後、表裏、回転表現、頻度逆転、逆再生、進行方向、方向と格子の Z 方向・拡散・重力を接続 |
| 第4回 | 出力 | 数、出力タイプ3～5、値を近似接続。タイプ8はオプション0のパスファイルとオプション1のスクリプト制御から `xyz/xyzd` を実行 |
| 第5回 | 回転 [パーティクル(R)]、集結点、拡大率と透過率 | 回転速度、集結座標、開始時刻、始終の拡大率・透過率を接続 |
| 第6回 | フィルター、フィルター(単色化専用) | フィルター名を接続。変化式と単色化専用処理は未接続 |
| 第7回 | 個別微調整、時間、時間2 | 速度ばらつきと速度周期の一部を近似接続。グラフ処理は未接続 |
| 第8回 | 跳ね返り、跳ね返り2 | XYZ範囲・反発係数、先頭の参照レイヤーを接続 |
| 第9回 | テキスト [パーティクル(R)]、画像、動画 | テキスト文字列、パステキスト、画像の単体／フォルダ選択を接続。粒子別動画再生は未接続 |
| 第10回 | 風 | UIは対照可能。旧グラフ評価は未接続 |
| 第11回 | 挙動、挙動2、挙動3、挙動4 | 挙動の `vector` 自作関数、挙動2の分散・停止、挙動3の中心・角速度を接続。挙動4は未接続 |
| 第12回 | 空間場、軌跡、ファンネル、メッシュ | 軌跡、ファンネル、`図形=pathN` のファンネル画像、メッシュ透過率を接続。空間場は未接続 |
| 第13回 | 立体物、ガラス化(二次元)、音 | 立体タイプ0～5・大きさ・分割数・曲率・奥行き、ガラス倍率、音の取得位置を接続。PMD由来 `.dat` は未対応 |

## 解説を参照するときの注意

- 記事の効果追加順はそのまま使えます。拡張効果は「パーティクル本体@particle2r」より上へ置きます。
- 記事のトラック名は原則そのまま UI から探せます。ver3.54B 側の表記が途中で欠けている `消失(ﾐﾘ秒` なども検索性のため原文を保持しています。
- 記事で「設定」ボタンを押す操作は、AviUtl2 では「詳細設定（旧版の『設定』）」を開く操作に相当します。
- 項目末尾の括弧は Lua 変数名です。スクリプト制御や同梱ソースを読むときは、この名前で検索できます。
- UI に表示されても計算へ未接続の項目があります。映像へ反映する範囲は[互換性一覧](compatibility.md)で確認してください。
- 旧 `.anm`、`.exa`、`.exo`、`.aup` を直接読み込む機能はありません。

## 代表例

| やりたいこと | 操作 |
|---|---|
| 基本の粒子 | 元画像へ「パーティクル本体」を追加し、`出力速度`、`出力頻度`、`出力方向`、`拡散角度`を調整 |
| 寿命を3秒にする | 本体の詳細設定で `生存時間(秒 (ju)` のスライダーを `3` にする |
| 重力を設定する | 本体の詳細設定で `各xy重力 (grav)` に `{0,100}` のように入力 |
| 透過率を変化させる | 本体の詳細設定で `透過率｛始、終｝ (palpha)` に `{100,0}` を入力 |
| Z方向へ飛ばす | 本体より上へ「方向と格子」を追加し、`z出力方向` と `z拡散角度`を調整 |
| 箱から発生させる | 本体より上へ「出力」を追加し、`出力ﾀｲﾌﾟ=4`、`値`を調整 |
| 自作関数の位置から発生 | 同じオブジェクトの標準「スクリプト制御」に `xyz(t)` または `xyzd(t)` を記述。「出力」を `出力ﾀｲﾌﾟ=8`、`ｵﾌﾟｼｮﾝ=1` にする。標準効果は本体の上下どちらでも置ける |
| 自作関数で動かす | 同じオブジェクトの標準「スクリプト制御」に `vector(t)` を記述。「挙動」の `orifunc=1` と `scriptf=1` を設定。標準効果は本体の上下どちらでも置ける |
| 外部ファイルの自作関数 | 「パス」でファイルと1～10の番号を指定。「出力」はタイプ8・オプション0・数を同番号にする。「挙動」は `orifunc=1`、`scriptf=0`、`pathn` を同番号にする |
| 途中で分散させる | 本体より上へ「挙動2」を追加し、`分散ﾀｲﾑms`、`xy拡散度`、`z拡散度`を調整 |
| 円運動させる | 本体より上へ「挙動3」を追加し、`中心x/y/z` と `角速度`を調整 |

元記事は組み合わせ方の知識として利用できます。スクリプト制御と「パス」の外部ファイルから3関数を実行でき、パス素材と前後表裏の主要操作も同名設定から利用できます。同梱の追跡例にある `obj.getvalue(layer..".x/y/z", t)` は直前レイヤーの座標参照として利用できます。それ以外のホスト関数は未対応です。数値計算、乱数消費順、表裏合成を含む描画処理は旧 DLL とまだ一致していません。
