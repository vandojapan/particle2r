# 本体と拡張効果（0.8.0-beta.2）

元の「パーティクル(R)」と同じ順序で、同じ画像オブジェクトに拡張効果を追加し、最後に「パーティクル本体」を置きます。

本体と31拡張は、すべて効果追加メニューの「パーティクル(R)」ラベルに登録されます。AviUtl2既定の「加工」には登録しません。

```text
画像・図形・テキストなどのオブジェクト
  画像                 ← 必要な素材の指定
  風                   ← 必要な拡張設定
  軌跡                 ← 必要な拡張設定
  パーティクル本体     ← 粒子を描画
```

拡張効果は単独で粒子を描画せず、本体が同じオブジェクトにある拡張設定を読み取ります。無効な効果と、本体より下の効果は読み取りません。同じ効果を複数置いた場合は、本体に近いものを後から適用します。

旧版の本体1件と拡張31件をすべて登録します。「回転」と「テキスト」は AviUtl2 標準効果との衝突を避けるため、それぞれ「回転 [パーティクル(R)]」「テキスト [パーティクル(R)]」という登録名です。

トラック、チェック項目、詳細設定は元スクリプト ver3.54B の表記を使います。詳細設定の項目名に表示される括弧内は Lua 変数名です。記事と見比べる方法は[記事との対照ガイド](original-article-guide.md)、各項目が映像へ反映される範囲は[互換性一覧](compatibility.md)を参照してください。

開発版は `aviutl2-cli` の `au2 develop --skip-start` で配置します。AviUtl2 2.1.9 のログで32プラグインと32効果の登録を確認し、登録エラーがないことを確認済みです。旧版との出力画像比較は未完了です。
