# P5 互換インポートと外部拡張（0.8.0-beta.2）

P5 は旧版と同じ効果名、追加順、設定操作を最優先にする。現在の「パーティクル本体」と31拡張 `.auf2` の中へ機能を追加し、汎用プラグインは作成しない。専用の補助プラグインは、既存 `.auf2` から必要なホスト機能へ到達できないことを確認した場合だけ検討する。

EXA/EXOインポートはbeta後へ延期し、[P6 性能・配布](p6-progress.md)と並行して旧操作の接続を進める。

## 現在の制限

外部Luaは数値関数 `xyz`、`xyzd`、`vector` を専用Lua状態で実行する。`math`、`string`、`table` と `obj.layer/time/totaltime/frame/totalframe/framerate` は利用できる。旧 AviUtl の描画状態へ接続する `obj.getvalue`、画像操作、任意DLLや外部プロセスの実行には対応しない。

0.8.0-beta.2では、旧記事の基本操作を優先する。ユーザーカスタムオブジェクト、他作アニメーション効果、PMD由来 `.dat`、EXA/EXO変換はbeta後も個別対応であり、存在するUIだけを対応済みとは扱わない。
