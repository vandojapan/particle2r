# P6 性能・配布（0.8.0-beta.2）

P6では旧版との数値互換とシーク再現性を保ったまま、連続再生時のCPU負荷、ホスト描画呼び出し数、Windowsでの再現可能な配布を改善する。EXA/EXOインポートは後続作業とし、P6の対象から外す。

## 実装済み

- [x] オブジェクトごとの `RenderWorkspace` で、現在の寿命・軌跡区間に必要な粒子初期値を最大10,000件再利用する。
- [x] シード、発生条件、寿命、ばらつき、分散、スクリプト出力が変わった場合は計算キャッシュを自動破棄する。
- [x] AviUtl2側のワークスペースを最大16オブジェクトに制限し、計算中はグローバルロックを保持しない。
- [x] 通常画像でXY回転がなく粒子別効果もない場合、最大2,048粒子を1回の `QuadTexture` 描画へまとめる。3D回転、連番、文字分割、立体、ガラス、粒子別効果は従来経路へ戻す。
- [x] 素材画像、背景、音声解析、外部Luaの既存キャッシュを維持し、粒子ごとに同一素材を複製しない。
- [x] 1千・1万粒、軌跡、ファンネルを同じ条件で測る `p6_benchmark` を追加する。
- [x] `PARTICLE2R_PROFILE=1` のとき、AviUtl2ログへ解像度、粒子数、計算・描画・合計時間を初回と60フレームごとに出力する。
- [x] Windows CIでテスト、基本版・拡張版のreleaseビルド、`au2 release`、パッケージ内容検査を行う。
- [x] beta版で32 `.auf2`、6文書、参照用の元 `.anm` 3件、自作関数サンプル11件をローカルのパッケージ検査で確認する。`.anm` は `templates/original` だけに置き、余分な `.aux2` / `.mod2` がないことも確認する。

## CPU計算測定

測定環境は Windows NT 10.0.20348、AMD64 Family 23 Model 1、論理3 CPU、Rust 1.98.1 GNU、releaseビルド。各ケース60フレームの中央値と95パーセンタイルを示す。解像度は計算コアの粒子座標計算時間へ影響しない。

| ケース | 生存粒子 | 出力要素 | キャッシュ前 中央値 | キャッシュ後 中央値 | 改善率 | キャッシュ後 p95 |
|---|---:|---:|---:|---:|---:|---:|
| 基本 | 1,000 | 1,000 | 1.977 ms | 0.054 ms | 97.3% | 0.076 ms |
| 基本 | 10,000 | 10,000 | 20.017 ms | 0.729 ms | 96.4% | 0.819 ms |
| 軌跡4点 | 1,000 | 5,000 | 2.298 ms | 0.314 ms | 86.3% | 0.358 ms |
| 軌跡4点 | 10,000 | 20,000 | 21.050 ms | 1.692 ms | 92.0% | 1.834 ms |
| ファンネル4子 | 1,000 | 5,000 | 2.109 ms | 0.189 ms | 91.0% | 0.213 ms |
| ファンネル4子 | 10,000 | 20,000 | 20.262 ms | 1.004 ms | 95.0% | 1.160 ms |

再測定は次のコマンドで行う。

```powershell
cargo run -p particle-core --example p6_benchmark --release --offline
```

AviUtl2実機測定では、起動前に `PARTICLE2R_PROFILE=1` を設定する。ログの `particle2r-profile` 行は同じ解像度・粒子数・出力要素数ごとに集計される。

出力ベクターの実データ量は基本1万粒で約0.46 MiB、軌跡またはファンネル込み2万要素で約0.92 MiB。RGBAフレームバッファ1枚は1920×1080で約7.91 MiB、3840×2160で約31.64 MiBとなる。背景参照やマスクでは追加バッファが必要になる。

## AviUtl2初回フレーム参考値

AviUtl2 2.1.9へreleaseビルドを配置し、図形素材、寿命3秒、定常粒子数1千・1万の各プロジェクトをフレーム150で開いた。値はプロジェクト読込直後の1フレームで、シェーダー、素材、パイプラインの初期化を含む。

| 解像度 | 粒子数 | 計算 | 描画 | 合計 |
|---|---:|---:|---:|---:|
| 1920×1080 | 1,000 | 2.561 ms | 36.876 ms | 39.437 ms |
| 1920×1080 | 10,000 | 24.530 ms | 2.537 ms | 27.067 ms |
| 3840×2160 | 1,000 | 2.631 ms | 4.822 ms | 7.452 ms |
| 3840×2160 | 10,000 | 26.625 ms | 3.103 ms | 29.728 ms |

4条件とも32プラグインとプロジェクトを読み込み、警告、Luaエラー、例外は0件だった。初回描画の外れ値とGPUの非同期実行を含むため、この表から60fps可否や解像度間の倍率を判定しない。定常値は同一プロセスで連続フレームを測る。

## 検証済み

- キャッシュ有無、順方向、逆方向シーク、設定変更後の結果が `RenderBatch` 単位で一致する。
- ホスト補助19件、計算コア29件、計48件のテストに合格する。ホスト補助には原本の自作関数サンプル11件を終点まで三角形用の描画値まで評価する回帰テストを含み、非ゼロ `degz` のZ方向回帰も含む。計算コアでは初期状態のZ回転が0であることも確認する。
- キャッシュは現在必要な粒子区間だけを保持し、1オブジェクト10,000件を超えない。
- バッチ化できない素材・3D回転・粒子別効果は個別描画へ戻り、機能を省略しない。
- `au2 develop --profile release --skip-start` で0.8.0-beta.2のrelease DLL 32件をAviUtl2 2.1.9へ配置した。0.8.0-beta.2をホストで起動し、32件すべての読込と登録エラー0件を確認した。「パーティクル(R)」ラベルは全32効果のメタデータテストで照合している。
- `au2 release` で `particle2r-v0.8.0-beta.2.au2pkg.zip` を生成した。32 `.auf2`、6文書、`templates/original` の `.anm` 3件・自作関数サンプル11件、予期しない `.aux2` / `.mod2` 0件を確認した。元ファイル14件はZIP内でも原本と同じSHA-256になっている。

## 残りのP6タスク

- [ ] AviUtl2実機で1080p/4K、1千/1万粒のホスト描画時間を同一プロセスの複数フレームで測定し、初回参考値と分けて記録する。
- [ ] 軌跡、ファンネル、メッシュ、ガラスの実機描画時間とGPUメモリ使用量を記録する。
- [ ] CIの最初の実行結果を、ローカル実機成功とは別に記録する。
- [ ] 実測で必要と判明した場合だけSIMDまたはGPU計算を検討する。

現時点では60fpsを保証しない。計算コアは1万粒でも中央値1 ms未満になったが、素材サイズ、粒子別効果、AviUtl2の合成処理を含むホスト描画時間は別に測定する必要がある。

非表示／最小化した実機へ再生・フレーム送りを自動入力する試験では、ホストが初回と追加1フレームだけを描画し、60フレーム集計へ到達しなかった。この値は定常測定へ採用していない。残りの実機測定はプレビューを前面で再生する手動手順か、AviUtl2側のフレーム駆動APIが必要である。
