# パーティクル(R) AviUtl2 移植

元の「パーティクル(R) ver3.54B」を参考にした、AviUtl2 用の Rust 製フィルタ効果です。元の 32bit Lua DLL は使用しません。元オブジェクトの画像を粒子として複数回描きます。

0.8.0-beta.2 では、旧版の「パーティクル本体」と31拡張を同じ効果名で分離し、元スクリプトから抽出した104トラック、チェック項目、`--dialog` の設定名と初期値を UI に反映しています。32個すべての `.auf2` は効果追加メニューの「パーティクル(R)」ラベルに入り、「加工」には入りません。AviUtl2 標準効果と衝突する「回転」「テキスト」の登録名には `[パーティクル(R)]` を付けています。説明書のスクリプト制御、旧パス番号の自作関数・画像・テキスト・ファンネル画像、前後表裏の主要切替、立体物タイプ0～5を接続しました。P6の連続フレーム計算キャッシュと同一素材の一括描画も含みます。対応状況は [互換性一覧](docs/compatibility.md) を参照してください。

## 使い方

1. [リリース ZIP](release/) の `.au2pkg.zip` を AviUtl2 のプレビュー画面へドラッグ＆ドロップします。手動配置する場合は ZIP 内の `Plugin/*.auf2` をまとめて `data/Plugin` に配置します。
2. 効果追加メニューの「パーティクル(R)」から、画像・図形・テキストなどのオブジェクトに「パーティクル本体」を追加します。
3. 「風」「軌跡」など必要な拡張効果を**同じオブジェクトの本体より上**に追加します。本体は上にある有効な拡張設定を読み取ります。複数ある場合は本体に近い側の同名設定を優先します。
4. 本体で出力頻度、方向、寿命などを設定します。出力頻度 100 は毎秒 10 回、出力速度 100 は 1 秒あたり 100 座標単位として扱います。同時発生数の既定値は 1 です。

各効果の「詳細設定（旧版の『設定』）」を開くと、旧 `--dialog` の項目が並びます。項目名の末尾に元 Lua 変数名を表示するため、解説の設定名とスクリプト制御を直接対照できます。配列は `{0,0}`、未指定は `nil`、文字列は `"文字"` の旧記法で入力します。拡張効果を無効にすると、その効果の設定は本体へ渡されません。

## 説明書のスクリプト制御

同梱説明書の `xyz(t)`、`xyzd(t)`、`vector(t)` を同じ記述で利用できます。

1. 同じオブジェクトに AviUtl2 標準の「スクリプト制御」を追加し、説明書や `自作関数サンプル` のコードを貼り付けます。
2. `@出力`相当では「出力」を追加し、`出力ﾀｲﾌﾟ=8`、`ｵﾌﾟｼｮﾝ=1` にします。`xyz(t)` の3戻り値を発生位置、`xyzd(t)` の4・5番目をXY/Z出力方向のラジアン値として使います。XY方向は旧版どおり `(sin(角度), cos(角度))` へ変換するため、説明書の半径300・速度100・寿命3秒の例は中心へ到達して消滅します。
3. `@挙動`相当では「挙動」を追加し、詳細設定の `*自作関数/chk (orifunc)=1` と `*ｽｸﾘﾌﾟﾄ制御記述/chk (scriptf)=1` にします。`vector(t)` の速度を粒子の生成後時間で積分して移動へ加えます。
4. 「スクリプト制御」「出力」「挙動」は「パーティクル本体」より上に置きます。

標準「スクリプト制御」のコードをホストから取得できない場合は、「出力」または「挙動」の `スクリプト制御コード（取得できない場合）` に同じコードを貼り付けられます。Lua の `math`、`string`、`table` と、`obj.layer`、`obj.time`、`obj.totaltime`、`obj.frame`、`obj.totalframe`、`obj.framerate` を利用できます。フレームレートはプロジェクトの値を使用します。`obj.getvalue` など描画ホストを呼ぶ関数は、この互換実行層では未対応です。

「パーティクル本体」の「終了時に消える」を有効にすると、旧説明書どおり全粒子の生存時間をオブジェクト終端までに切り詰めます。終端を参照するサンプルスクリプトでも、最後のフレームで残留しません。

外部ファイルを使う場合も旧説明書と同じ操作です。同じオブジェクトの本体より上へ「パス」を追加し、`パス番号=1～10` と `.txt` または `.lua` ファイルを指定します。「出力」は `出力ﾀｲﾌﾟ=8`、`ｵﾌﾟｼｮﾝ=0`、`数=パス番号`、「挙動」は `orifunc=1`、`scriptf=0`、`pathn=パス番号` にします。UTF-8、UTF-8 BOM、Shift_JISを読み取ります。ファイルを変更すると更新日時を検出して再読込します。

同じパス番号は「画像」の `ﾊﾟｽ番号`、「テキスト」の `ﾊﾟｽ取得0~10`、「ファンネル」の `図形=path1`～`path10` でも使えます。「パス」の「単体」が無効なら選択ファイルと同じフォルダを列挙し、「画像」の「ぱらばら」が0なら名前順、1なら粒子ごとの決定的な順で選択します。「立体物」はタイプ0～5と分割数・曲率・奥行きを描画します。タイプ6の旧PMD変換 `.dat` はbetaでは未対応です。

「前後表裏その他切替」は、前後の描画順、表／裏、回転表現1～6、頻度逆転、逆再生、進行方向を反映します。旧版の表裏合成は比較資料が不足しているため未対応です。

さつき氏の「拡張パーティクル(R)の使い方」は、[記事との対照ガイド](docs/original-article-guide.md)と併せて参照してください。効果名と設定名は原則そのまま探せます。ガイドには AviUtl2 での表示方法と、まだ描画へ接続していない項目をまとめています。

元ZIPの `.anm` 3件と `自作関数サンプル` 11件を、配布パッケージの `templates/original` に原本のまま収録しています。`.anm` は AviUtl 1.x 用の参照テンプレートなので、AviUtl2 が自動読込する `Plugin` / `Script` には配置していません。利用方法と文字コードは [`templates/original/README.md`](templates/original/README.md) を参照してください。

発生形状は `0=点`、`1=水平線`、`2=箱内`、`3=球面` です。範囲 X/Y/Z は発生領域の大きさで、球面では X を直径として使用します。重力は座標単位/秒²、寿命と開始時間は 1/100 秒単位、透過率と拡大率はパーセント値です。最大描画粒子数は 10,000 個です。

Z 出力方向と Z 拡散角度で奥行き方向への飛行を設定できます。Z 回転の初期角度は粒子ごとに決定し、既定では毎秒 60 度回転します。角度と乱数の消費順は旧 DLL との視覚比較前の暫定仕様です。

P3 の風、個別ばらつき、時間、集結、跳ね返り、挙動2・3、軌跡はそれぞれ独立した拡張効果です。軌跡モードは `0=無効`、`1=残像`、`2=白色帯`、`3=小さな画像点` です。計算順と上限は [P3 仕様メモ](docs/p3-design.md) に記載しています。

P4 で追加した画像参照、マスク、連番、テキスト分割、粒子別フィルタ、ファンネル、メッシュ、立体、ガラス、音声解析の計算コアは残しています。旧 UI から接続できる設定はまだ限定的です。[P4 計算コア](docs/p4-progress.md)、[P5進捗](docs/p5-progress.md)、[P6進捗](docs/p6-progress.md)、[互換性一覧](docs/compatibility.md)を参照してください。

## 開発

開発環境は [aviutl2-cli](https://github.com/sevenc-nanashi/aviutl2-cli) の `au2` コマンドです。設定は [aviutl2.toml](aviutl2.toml) にあり、AviUtl2 2.1.9 と `aviutl2` クレート 0.46.1 を指定しています。通常の Windows Rust 環境では以下を実行します。

```powershell
au2 prepare
au2 develop
au2 release
```

Windows x64 と Rust 1.98 以降を想定します。MSVC ターゲットの場合は Visual Studio C++ Build Tools が必要です。計算コアだけを確認する場合は `cargo test -p particle-core` を実行します。この作業環境では MSVC リンカがないため、GNU ターゲット、Rust 同梱 `rust-lld` と MinGW binutils でビルドしました。ソースは MSVC 固有の API を使用していません。

`au2 develop --skip-start` による配置と、AviUtl2 2.1.9 のログで本体・31拡張の計32効果がエラーなしで登録されることを確認しました。実際の積層効果を操作した画面と旧版の出力画像の比較は未実施です。

## 構成

- `crates/particle-core`: ホスト非依存の MT19937、発生・運動・寿命の計算。
- `crates/particle-aviutl2`: 設定 UI、時刻の取得、元画像の描画。
- `docs/compatibility.md`: 旧 32 項目との対応範囲。
- `docs/p3-design.md`: P3 の計算順・時間単位・未確定事項。
- `docs/p4-progress.md`: P4 の実装範囲、時間・参照・負荷の規則、旧版との差。
- `docs/p5-progress.md`: P5 の実装方針、実装済み項目、残タスク。
- `docs/p6-progress.md`: P6 の性能測定、最適化、配布検証。
- `docs/stacked-effects.md`: 本体と拡張効果の追加順、対応効果、既存プロジェクトとの関係。
- `docs/original-article-guide.md`: さつき氏の旧版向け記事を AviUtl2 で読む際の効果名と操作の対応。
- `templates/original`: 元ZIPの `.anm` テンプレートと自作関数サンプル。

元 DLL の解析根拠は [移植計画書](Particle_R_AviUtl2_Port_Plan.md) と `Particle_R_Analysis_Evidence.zip` にあります。乱数生成器とシード混合式は解析値に合わせていますが、粒子ごとの乱数消費順や描画順は旧版から完全復元されていません。
